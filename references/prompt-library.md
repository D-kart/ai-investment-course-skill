# Prompt Library — 20 条可复用提示词库

> 每条 prompt 对应一门课，围绕「AI 增强投资」场景设计，可直接复制使用。
> 完整五段式详情（背景/场景/prompt/技巧/FAQ）由 prompt + 各段说明构成。
> 使用时按讲师/机构视角替换【占位符】。

## 01 · AI 能力边界与投资场景适配

**Prompt 名**：七维度能力自评 + 投研环节适配矩阵

```
你是一名资深一级市场投资人，请以「七维度能力评分模型」评估自己处理以下任务的能力，并给出投研环节适配建议。

七维度：信息检索与摘要（92）、结构化写作（78）、逻辑推理（65）、数据与计算（52）、创造性洞察（38）、实时决策（27）、市场判断（18）。

请针对以下任务逐一回答：
1. 该任务属于哪个维度？我的评分多少？
2. 我的输出中，哪些部分可信、哪些部分必须人工复核？
3. 给出该任务的「AI 承担 + 人工兜底」分工建议。
4. 如果我做错了，最可能的错误模式是什么？

任务：[在这里粘贴具体任务，如「分析这份 BP 的商业模式」「判断这家公司该不该投」]
```

**KEY TAKEAWAY**：真正的差距不是「用没用 AI」，而是「把 AI 当词典还是当同事」——当工具人人可得，拉开身位的是信号解读水平与体系化程度。

## 02 · 工具矩阵与成本结构

**Prompt 名**：工具选型与成本结构咨询

```
你是一名 AI 投资工具选型顾问，熟悉 2026 年主流 AI 工具与定价。请帮我做一份工具选型方案。

我的背景：一级市场股权投资机构，团队 [人数] 人，同时跟踪 [N] 条赛道，每月处理约 [数量] 份材料（BP、财报、招股书、访谈纪要、行业报告）。

请输出：
1. 五类工具各推荐 1 个主选 + 说明理由（常用辅助 / 国产编程助手 / 个人智能体 / 境外旗舰订阅 / 按量计费接口）
2. 成本结构：哪些任务走低价模型、哪些必须旗舰模型，估算每月成本区间
3. 敏感材料处理建议：哪些信息不能上传、用什么替代方案
4. 选型原则：我只需要每类选一个，请按我的场景取舍，不要罗列全部选项

补充信息：[团队技术能力、预算、是否涉及保密项目]
```

**KEY TAKEAWAY**：工具是弹药，不是军火库——按「任务频率 × 价值密度」决定投入：高频低价任务全自动化，低频高价值任务才值得上旗舰模型。

## 03 · AI 时代投资人的一天

**Prompt 名**：AI 增强版投资人 24 小时工作流规划

```
你是一名资深投资机构运营顾问。请帮我规划一个「AI 增强版投资人 24 小时工作流」，覆盖一级市场股权投资日常。

我的角色：[分析师 / 投资经理 / 合伙人]，关注赛道：[赛道]，今日重点工作：[如「推进 XX 项目尽调」「准备投委会材料」]。

请按时间线输出（07:00-23:00，每时段 1-2 行）：
1. 该时段的业务动作
2. AI 具体承担什么（如自动抓取、解析、起草、监控）
3. 效率提升点与人工复核点

参考效率基线：晨间简报 3 分钟读完、项目筛选效率提升 2-3 倍、合格交易流量 +40-60%、尽调 8h→2h。

请基于我的角色和今天重点，给出定制化方案，不要泛泛而谈。
```

**KEY TAKEAWAY**：AI 时代投资人的一天不再是「赶材料」，而是「审材料 + 做判断」——把 80% 的案头时间压缩后还给访谈、思考和决策，这才是时间复利。

## 04 · 行业研究与赛道分析

**Prompt 名**：产业作战地图 + 关键风险识别

```
你是一名资深一级市场行业研究员。请基于以下信息，完成一次行业研究与风险识别。

输入材料（可多份）：[粘贴 BP / 公众号文章 / 招股书摘录 / 新闻，或描述你掌握的全部信息]

请输出：
1. 产业作战地图：细分赛道、已投项目（如有）、在看标的、主要竞对布局，一屏铺开
2. 市场规模测算：TAM/SAM/SOM，注明测算口径与假设
3. 竞争格局：头部集中度、进入壁垒、价值链利润分布
4. 产业链拆解：上中下游结构、关键环节、成本传导
5. 关键风险：至少识别 3 个（优先从信息中找，而不是泛泛而谈）——特别注意：财务数据难以发现的风险（如供应链依赖、产能瓶颈）
6. 待验证问题清单

要求：所有结论标注信息出处；信息不足处明确说「信息不足，需补充」；不要输出主观星级评分。
```

**KEY TAKEAWAY**：行业研究的终点不是「看懂」，而是「在别人还没看懂前建立认知差」——AI 拉平了研究速度，认知差只剩两个来源：问题质量和验证深度。

## 05 · 项目筛选与信号打分

**Prompt 名**：项目批量预筛 + 信号打分

```
你是一名一级市场投资分析师，按以下标准筛选项目。

【机构投资标准】
- 赛道：[如「AI 基础软件」]；阶段：[A/B 轮]；单笔金额：[区间]
- 硬性门槛：[如「毛利率 > 60%」「创始团队有产业背景」]
- 一票否决项：[如「存在未披露的重大诉讼」「收入依赖单一大客户」]

【任务】请对以下项目逐一输出项目卡片（每个 150 字内）：
1. 一句话定位 + 所处赛道
2. 关键指标速览（融资/营收/团队/客户）
3. 是否符合硬性门槛（通过/待核实/不通过）
4. 信号打分（1-5 分）+ 打分理由
5. 是否进入下一轮（建议/待定/放弃）

【项目材料】
[粘贴多份 BP 或项目简介，用分隔符隔开]

要求：打分必须可解释、可回溯；信息不足标注「待核实」，不要臆测。
```

**KEY TAKEAWAY**：打分卡就是你的投资策略——「你写进筛选标准里的，才是你真正相信的」；AI 只是把策略从人脑搬进代码，让标准不再随情绪漂移。

## 06 · 商业计划书拆解与速析

**Prompt 名**：BP 拆解 + 美化手法识别

```
你是一名审阅过上千份 BP 的一级市场投资经理。请拆解以下商业计划书。

【BP 原文】
[粘贴 BP 全文或关键章节]

请输出：
1. 商业模式一句话：谁、卖给谁、怎么赚钱、靠什么壁垒
2. 行业与市场：目标市场测算（含口径质疑），竞品格局速览
3. 创始团队核实：学历/经历/历史创业记录（如果信息不足，列出需核实的渠道）
4. 历史融资梳理：轮次、金额、投资方、估值变化
5. 美化手法识别——重点检查：
   - 毛利率数据是否缺失或虚高
   - 目标市场规模是否「把整个赛道当自己的市场」
   - 一次性收入（硬件/集成）是否与持续性收入混在一起
   - 估值锚定逻辑是否成立
   - 客户集中度是否被隐藏
6. 一页纸投资亮点与风险总评

要求：全部以事实定量论证，不输出聚合分数、不打星级；风险写在亮点前面。
```

**KEY TAKEAWAY**：最好的 BP 分析不是「看懂它写了什么」，而是「找出它没写什么」——AI 负责穷尽信息，人负责追问缺口；被掩盖的往往比展示的更重要。

## 07 · 尽职调查全流程 AI 工作流

**Prompt 名**：尽调访谈纪要官（结构化转录）

```
你是投资机构的访谈纪要官。请把以下访谈录音转写文本整理成正式纪要。

【转写文本】
[粘贴录音转写，可能含口语化、发言混乱、重复]

请输出：
1. 访谈信息：时间、地点、参与方（尽量区分发言人）
2. 按主题归并的内容（五大类：行业与市场 / 团队与股权 / 产品与技术 / 财务与经营 / 风险与合规），每类下列出关键事实
3. 关键数字单独列出并注明出处句
4. 待确认事项清单（访谈中提到但未确认的问题）
5. 后续动作（谁负责、什么时间）

要求：客观陈述、不脑补；口语内容清洗为标准表达；发言人无法区分时标注「无法区分」；不确定的事实标注「待核实」。
```

**KEY TAKEAWAY**：尽调的终极目标不是「做出一份报告」，而是「建立一条可审计的证据链」——AI 的价值在于让证据链完整、可追溯，让每一句结论都能指到出处。

## 08 · 财务分析与模型辅助

**Prompt 名**：财报结构化提取 + 异常信号筛查

```
你是一名 CFO 背景的财务分析师，专长是识别财务舞弊信号。

【财报材料】
[粘贴上市公司年报/招股书财务章节，或描述数据]

请输出：
1. 三年核心财务数据表（收入/毛利/净利/经营现金流/资产负债率），标注增长率
2. 收入质量分析：收入确认政策、现金收入占比、应收增速 vs 收入增速
3. 盈利质量：毛利率趋势与同行业对比、费用结构异动
4. 异常信号筛查（重点）：
   - 利润与现金流长期背离
   - 存货增速远超收入增速
   - 毛利率异常高或突然跃升
   - 关联交易占比异常
   - 应收账龄恶化
5. 估值相关：可比公司/可比交易的参考区间

要求：所有数字标注来源与计算方式；数值计算请人工复核（AI 不擅长精确运算）；对每个异常信号给出「需要进一步核实的问题」。
```

**KEY TAKEAWAY**：财务模型的价值不在「算得准」，而在「假设说得清」——AI 帮你把假设结构化、把参数显性化，人负责判断每个假设是否成立。

## 09 · 投决输出与智能体投委会

**Prompt 名**：智能体投委会 · 四角色质询

```
你是一场投资决策质询会的主持人。请扮演四个角色对以下投资建议进行质询：

【投资建议】
[粘贴投资备忘录/投决报告摘要]

四个角色：
1. 行业分析师：质疑赛道判断——市场规模是否高估？竞争格局是否恶化？技术路线是否会被颠覆？
2. 财务分析师：质疑财务逻辑——收入预测是否激进？毛利率假设是否成立？现金流能否支撑？
3. 蓝军质询官：专挑逻辑漏洞——最坏情况下这笔投资会怎样失败？哪些信息是我们在自欺欺人？
4. 风控裁决官：检查风险控制——仓位是否超限？集中度是否过高？止损条件是否明确？

请按顺序让每个角色发言（每人 3-5 条质询），然后主持人总结：哪些质询成立、哪些可以驳回、投资建议是否需要修改。

要求：质询要具体、要针对材料细节，不要泛泛而谈；对每个质询给出「成立/待核实/不成立」判定。
```

**KEY TAKEAWAY**：智能体投委会不是「让机器投票」，而是「让每个观点都必须被质询」——蓝军质询官是 AI 最被低估的角色：它专挑你的逻辑漏洞，专治团队确认偏误。

## 10 · 并购推介与交易支持

**Prompt 名**：并购推介书生成（年报 → 买方视角）

```
你是一名资深并购顾问。请基于以下上市公司年报信息，生成一份面向潜在买方的并购标的推介书。

【年报/公司信息】
[粘贴年报摘要或公司核心信息]

请输出（10 节结构）：
1. 公司速览：业务、规模、行业地位
2. 价值逻辑：为什么这家公司值得买（3 条核心投资逻辑）
3. 财务分析：近 3-4 年收入/利润/现金流趋势，盈利能力与质量
4. 买方战略匹配：这家公司对「财务型买方」与「战略型买方」各有什么吸引力
5. 协同效应测算：列出收入协同与成本协同的具体来源，标注假设与不确定性
6. 可比交易对标：估值倍数区间（P/E、EV/EBITDA）与近期可比交易
7. 风险矩阵：Top 5 风险 + 缓解措施
8. 整合路线图：并购后 100 天关键动作

要求：协同效应每个假设都要可验证；风险写在前面；不要用笼统表述。
```

**KEY TAKEAWAY**：并购里 AI 最值钱的能力是「协同效应测算的透明度」——估值分歧常常来自对协同的乐观假设，AI 能把每个假设摊开检验，让定价回归理性。

## 11 · 知识库与经验资产沉淀

**Prompt 名**：知识库入库质量检验

```
你是一个知识库管理顾问，帮我验证知识库建设质量。

我的知识库现状：[描述你建的库：主题、材料类型、数量]

请回答：
1. 验收标准检验——用 5 个真实业务问题测试我的知识库，每个问题回答：「能否从库中找到答案 / 找到的路径 / 缺失的材料」
2. 材料质量评估：我喂入的材料是「真实且会反复使用的」吗？哪些该删、哪些该补？
3. 结构优化建议：按用途分建专用库（行业库/交易库/人脉库）是否清晰？
4. 习惯设计：每天十分钟入库的具体动作是什么？每周用一个真实问题检验怎么做？

我的业务方向：[投资方向/常用材料类型]
```

**KEY TAKEAWAY**：机构级 AI 复利 = 知识库（记忆）+ 技能包（能力）+ 工作流（组织）——三者沉淀下来，机构能力不再依赖任何单一个人。

## 12 · 幻觉治理、数据安全与合规

**Prompt 名**：AI 输出交叉比对核验

```
你是投研材料的终审编辑。以下是一份 AI 生成的投研材料，请进行严格交叉比对核验。

【AI 输出】
[粘贴 AI 生成的报告/纪要/摘要]

【原始材料】
[粘贴引用的原始资料：财报、招股书、访谈记录、新闻]

请逐项核验：
1. 事实一致性：AI 输出中的每个数字、日期、人名、公司名是否能在原始材料中找到？列出「匹配 / 不匹配 / 找不到出处」三项清单
2. 引用核验：每个引用来源是否真实存在？引用是否断章取义？
3. 逻辑外推：是否存在「根据已知线性外推」的未证实结论？
4. 幻觉标记：有没有编造的事实、数据或引用？
5. 合规检查：材料中是否有敏感信息（未公开交易、涉密数据）？

输出格式：问题清单（严重/一般/提示）+ 修正建议。未获证实的事项必须标注「未获证实」。
```

**KEY TAKEAWAY**：投资机构用 AI 的底线不是「快」，而是「可解释、可追溯、可问责」——做不到这三点，快就是风险；做得到，AI 才是可信的投研同事。

## 13 · AI 募资：把 LP 尽调答成 30 分钟

**Prompt 名**：LP 尽调问答库（DDQ）自动应答

```
你是一名基金募资合伙人，正在应对 LP 尽调。

【基金信息】
- 基金概况：[名称、规模、策略、存续期]
- 历史业绩：[各期基金 IRR/MOIC/DPI，代表项目]
- 团队：[核心成员、从业年限、分工]
- 差异化：[独特资源/生态/方法论]

【LP 类型】[国资 / 险资 / 家族办公室 / 政府引导基金]

请输出一份针对该 LP 类型的尽调应答手册：
1. 该类 LP 最关心的 Top 10 问题（按权重排序）
2. 每个问题的标准应答（150 字内，含数据支撑）
3. 历史业绩叙事线：把数据组织成「为什么我们能重复赚钱」的逻辑链（3 条）
4. 该类 LP 的敏感雷区与应对话术
5. 需要团队准备但当前缺失的材料清单

要求：应答要有数据、有逻辑、一致性强；不要回避业绩波动，准备好解释。
```

**KEY TAKEAWAY**：募资的本质是「重复讲同一个故事直到被相信」——AI 让每次讲述都完整、一致、有据，把人从复制粘贴里解放出来去读 LP 的表情。

## 14 · AI 投前筛查：把 1000 个项目压成 10 个

**Prompt 名**：项目源雷达 + 批量预筛

```
你是投资机构的项目源雷达系统。

【关注赛道】[如：AI 应用、半导体设备、新能源]
【信号维度】融资动态、工商变更（新设子公司/增资）、招聘扩张、竞品融资、政策利好
【数据来源】[可接入的公开数据源/新闻/数据库]

请设计并模拟输出：
1. 项目源雷达的监控规则：每个信号维度定义「什么算值得注意的信号」（如「B 轮前新增注册资本 > 1000 万」「3 个月内招聘量翻倍」）
2. 今日扫描模拟：基于当前公开信息，输出 5 个值得关注的目标（公司名、信号类型、初步判断）
3. 预筛打分卡：5-8 个维度 + 评分锚点 + 一票否决项
4. 输出格式：项目卡片（200 字内，含进入下一轮的建议）

要求：信号要可量化，不要模糊表述；信息不足标注「待核实」。
```

**KEY TAKEAWAY**：筛查不是「多看一眼」，而是「标准先行」——把机构的投资策略写进打分卡，AI 只是执行器，标准质量才是胜负手。

## 20 · 现场实操：1 小时设计你的第一个投资类 skill

**Prompt 名**：投资类 skill 设计工作坊

```
你是技能包设计导师，帮我把一个日常痛点设计成可复用的投资类 skill。

【我的痛点】
[描述：我反复在做的专业动作，如「每周要整理 10 份 BP 摘要」「每次访谈后要写纪要」]

【设计步骤】请按以下框架输出 skill 设计方案：
1. 技能定位：这个 skill 解决什么问题？输入是什么？输出是什么？
2. 触发场景：什么时候自动触发（如「新 BP 上传时」「访谈录音完成后」）
3. 工作流步骤：3-6 步，每步做什么、调用什么
4. 规则与底线：输出规范（格式、长度、数据要求）、禁止项（不编造、不评分、风险前置）
5. 质量检验：如何验证输出达标（自检清单）
6. 迭代机制：首次跑通后如何收集反馈、持续改进

【示例参考】
一个优秀 skill 的设计哲学：不输出聚合分数、拒绝主观星级、全部以事实定量论证、风险写在正文前面。
```

**KEY TAKEAWAY**：今天讲的全景地图，每一个课题都是一条系列课引线——募资篇、尽调篇、投后篇、招商专题，方法论体系化才是第一讲真正的交付。

## 使用提示

1. **替换占位符**：【】内内容替换为真实材料，不要原样照抄
2. **保持提问视角**：prompt 以投资人第一人称/机构视角设计，让 AI 扮演专业角色（CFO、并购顾问、招商顾问等）
3. **强制输出结构**：每条 prompt 都有明确的编号输出格式，避免 AI 发散
4. **加人工复核条款**：涉及数字、估值、财务的 prompt 必须含「数值计算请人工复核」
5. **加反幻觉条款**：要求「信息不足标注待核实」「不编造」「风险写在前面」
