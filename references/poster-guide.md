# Poster Guide — 课程海报文案规范

> 用于生成「AI 增强投资」培训课程的招生海报文案。输出为 Markdown（文案 + 视觉规范注释），可直接复制到 Figma / Canva / PPT / PS 制作海报。

## 1. 海报文案结构（自上而下）

### 开场三段式

```
★ 系列课第一讲 ★            ← 金色小标签，宽字距，14px
AI 赋能全流程投研实战         ← 主标题，72-88px 粗体居中
把 AI 用进募投管退全流程，让每一位投资人都成为「AI 增强投资人」  ← 钩子副标题
```

- 主标题必须醒目、可读、占视觉主导
- 副标题用「动词+收益」句式，让人立刻知道"我来了能得到什么"
- 可选加机构品牌行：`· MAOSHU AI NATIVE INVESTMENT OPC · 出品`

### 中部卖点区

```
> AI 不会取代投资人，但会用 AI 的投资人会取代不会用的。   ← 金句（> 引用块）

你将在一天内获得：
- 摸清 AI 能力边界：哪些环节放心交给 AI、哪些必须人工兜底
- 掌握募投管退全流程 AI 工作流：核心环节效率提升 2-3 倍
- 探索募资、政府招商、基金管理等前沿场景的 AI 应用
- 现场 1 小时实操，设计你自己的第一个投资类 skill
```

- 金句是海报的灵魂，必须是有观点的断言，不是口号
- 收获 3-5 条，每条「动词 + 可量化收益」，避免空泛

### 课程数据表格

| 指标 | 数据 |
|---|---|
| 课程数量 | 20 门课 |
| 课程模块 | 4 大模块 |
| 总时长 | 约 690 分钟（净课时 650 分钟） |
| 授课形式 | 讲解演示 + 现场实操 + 案例拆解 |
| 讲师 | MAOSHU · 十余年股权投资与并购实操经验 |

- 数字是信任状，放课程规模让报名者快速建立预期
- 讲师行是转化关键——资深经历写实，不虚饰

### 四大模块（层次分明）

每个模块：模块名（##）+ 一句话引言（>）+ 课程清单
- 模块一~三课程清单平铺
- **模块四「前沿探索」8 个课题加粗**——这是差异化卖点，视觉上要强化

### 底部转化区

```
适合谁来听（5 类人群）
课程亮点（4 条，含"每个课题带一份可直接复制的 AI 提示词"）
报名方式：二维码占位 + 行动号召「长按识别二维码 · 添加企业微信 · 锁定席位」
```

- 报名区块用深色底收尾，做视觉锚点
- 行动号召动词化（锁定席位 / 抢占名额）

### 底部小字

- 系列课承接预告：AI 募资深潜 / AI 尽调深潜 / AI 投后深潜 / 政府招商与基金联动专题

## 2. 视觉规范（供海报设计参考）

### 配色方案（二选一）

**方案 A · 深墨金（金融权威感 · 推荐）**
- 主背景：米白 `#F8F4ED`（宣纸质感）
- 主标题：深墨 `#1A1A1A`
- 强调色：金 `#B08D3E`（模块分隔线、关键词、星号）
- 正文：`#4A4A4A`
- 报名区块：深墨 `#1A1A1A` 底 + 米白字

**方案 B · 黑金（大气硬朗）**
- 主背景：纯黑 `#0F0F0F`
- 主标题：白 `#FFFFFF`
- 强调色：金 `#C9A84C`
- 正文：`#C9C9C9`
- 报名区块：金 `#C9A84C` 底 + 黑字

### 字号层级（以 A4 / 1080×1350 海报为基准）

| 元素 | 字号 | 样式 |
|---|---|---|
| 期数标签 | 14px | 金色，宽字距 |
| 主标题 | 72-88px | 粗体居中，一行或两行 |
| 副标题 | 20px | 灰色 |
| 板块标题（##） | 28px | 加粗，上方留白 |
| 板块引言（>） | 16px | 灰色 |
| 课程条目 | 15px | 行距 1.8 |
| 数据表格数字 | 18px | 加粗 |
| 报名标题 | 22px | 加粗 + 强调色 |

### 排版层次建议

- 顶部：期数标签 → 主标题 → 副标题（三段式开场）
- 中部：金句(>强调) → 收获 → 数据 → 四模块
- 底部：报名区（深色块收尾，视觉锚点）
- 用 ★ 与 —— 做模块分隔，不用彩色贴纸感元素
- 每屏信息量克制，留白充足——海报不是课程表，只放钩子不放全量

### 字体建议

- 中文标题：思源宋体 Heavy / 方正兰亭黑 Heavy
- 中文正文：思源宋体 Regular / 苹方
- 数字/英文：Playfair Display / Didot（衬线数字更高级）

## 3. 文案写作原则

1. **钩子标题 + 落地干货**：标题抓人（"把 LP 尽调答成 30 分钟"），正文全是方法与数据
2. **金句先行**：一句有观点的断言定调（"AI 不会取代投资人，但会用 AI 的投资人会取代不会用的"）
3. **可量化**：效率 2-3 倍、+40-60%、8h→2h、0.45 元——数字比形容词可信
4. **差异化突出模块四**：募资/招商/基金管理是传统 AI 课不讲的新场景
5. **不用 emoji**：用 ★ ◆ —— 做装饰；海报的"大气感"来自留白与层次，不是贴纸
6. **二维码 + 行动号召收尾**：转化动作唯一且明确
